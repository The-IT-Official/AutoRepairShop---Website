Auto Repair Shop Website built by Nathan for a local repair shop Aemmz.

🚗 Overview
A professional, responsive website for Aemmz Auto Repair, a local automotive service provider. This project was built as a community service initiative to help establish their online presence and reach more customers.

✨ Features

Responsive Design: Fully mobile-friendly layout that adapts to all screen sizes
Service Showcase: Comprehensive listing of 12+ automotive services
Contact Integration: SMS and phone call functionality built-in
Interactive Map: Location page with embedded map for easy directions
Modern UI/UX: Clean, professional design with smooth navigation
Fast Performance: Optimized assets and deployment on Vercel

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript
Backend: Python (Flask/Django)
Deployment: Vercel
Assets: WebP optimized images

🔧 Installation & Setup

Clone the repository:

bashgit clone https://github.com/The-IT-Official/AutoRepairShop---Website.git
cd AutoRepairShop---Website

Install dependencies (if using Python backend):

bashpip install -r requirements.txt

Run locally:

bashpython app.py
# or open home.html directly in browser

Deploy to Vercel:

bashvercel deploy
